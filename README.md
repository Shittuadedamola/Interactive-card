Interactive Card App 💳

An interactive front-end application that allows users to enter their
information and see it displayed on a dummy credit card in real time. The
project focuses on creating a dynamic user experience through form inputs and
DOM manipulation.

FEATURES

Cardholder Name: Updates the card with the user's name.

Card Number Formatting: Formats the entered card number into groups of four
digits for a realistic card appearance.

Expiration Date: Displays the expiration date provided by the user.

Card Security Code: Displays the entered security code on the dummy card.

TECHNOLOGIES USED

HTML5

CSS3

JavaScript

DOM Manipulation

Event Listeners

Improving the user experience through interactive design.

IMPORTANT NOTE

This project is for demonstration and educational purposes only. The displayed
card is a dummy card and is not connected to a bank, payment processor, or
financial institution. Do not enter real credit card information or sensitive
financial details.
